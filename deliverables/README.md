# Evaluator review package

TrustGateIoT-Level2.zip contains source, setup instructions, the implementation
report, original proposal assets and dated test evidence. It contains no Wi-Fi
credentials, private keys or compiled firmware. SHA256SUMS.txt inside the archive
lists the packaged files and their hashes.

Start with README.md and docs/setup.md. The lab is local and requires Ubuntu/WSL
plus regenerated keys; physical board tests additionally require an ESP32.
Saved result files are recorded evidence, not a live demonstration.

The existing YouTube link is the introduction/proposal video. The final working
demo remains to be recorded and linked by the team. See docs/demo-walkthrough.md.
